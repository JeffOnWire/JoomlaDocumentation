Using the text editing tools in Joomla, learn how to create bold, italic, underline and strikethrough text in an article.

Prerequisites

  • 1 Tutorial Introduction covers where to run your tutorial and administrative access.

Steps

  1. Log in to Joomla backend and navigate to the Home Dashboard.
  2. In the Administrator Menu, click Content > Articles.
  3. Click on the New button. Result: A new-article form appears.
  4. The text editing area consists of a toolbar and an area in which to enter text.
  5. Hover over the toolbar items and note that a tool tip displays the name of the item.
  6. Click on the Bold (B) icon. Result: The icon is highlighted, indicating Bold is selected.
    • Clicking the icon again deselects the feature.
    • Clicking on any of the button icons toggles them on or off.


  7. Select any of the features and type in the text area. Note that the text appears in the format indicated in your item selection.
  8. Now highlight any of the text you've typed. Result: A small popup toolbar appears with the bold, italic, and underline icons.
    • Clicking on any of the icons updates the selected text.
    • The popup toolbar and main toolbar icons both will update the text.
  9. When you're done, click the Cancel button at the top of the form.

Concepts

The text editing area is referred to as the TinyMCE editor, a plugin that comes standard with Joomla.

The options available can be customised by the administrator.

There are a number of very powerful features that are explored in other tutorials.
