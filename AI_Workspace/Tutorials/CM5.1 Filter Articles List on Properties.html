If you want to find an article fast, you can filter the list of articles on various properties. This article explains how to do that.

As an example, we’re going to filter our articles list on

  • Status
  • Category
  • Status, Category and Author (multiple filters at once)

Prerequisites

  • 1 Tutorial Introduction covers where to run your tutorial and administrative access.
  • A website with multiple articles. If you haven’t created any articles yet, see 2.1 Creating an Article and Menu Item.

Steps

Navigate to the articles list

  1. Log in to Joomla backend and navigate to the Home Dashboard.
  2. In the Administrator Menu, expand Content and click on Articles. A list of articles appears
  3. Open the Filter Options by clicking the button on top of the list. The filter options appear.


Filtering on article status

We're going to start by filtering only articles that have a specific status, in our case Unpublished.

  1. In the Select status dropdown on top of the article list, select Unpublished

  2. Our list will now only show unpublished articles:

You can choose one of the statuses (Trashed, Unpublished, Published, Archived, All) to filter your articles list. 

You can reset the filter by selecting Select Status instead of Unpublished.

Filtering on category / categories

Our example website has multiple categories. You can filter on one or more categories. First we'll filter on the Typography category, then we'll filter on Blog category as well.

  1. In the Select Category dropdown on top of the article list, we select Typography.

  2. You'll see the list has gotten shorter, and in the dropdown your selected category is shown.



  3. Now we'll add a second category to the filter. Select Blog from the dropdown.



  4. You'll see both Typography and Blog visible in the dropdown the list now has articles from both categories:




  5. Remove Blog from the filter by clicking the little x-sign behind the highlighted category title. The list refreshes to show only Typography articles.
  6. Click Clear next to the Filter Options button. The list refreshes showing all articles.

Filtering on Status, Category and Author

In this example, we'll filter on Status, Category and Author. Like with the categories filter, we can filter on multiple authors. Here we've selected two authors and two categories.

  1. Click on Filter Options to reveal the filter choices. Select the following filter options:
    • Status: Published
    • Categories: Blog and Help
    • Authors: Joomla Tester and Joombassador



Concepts

  • Articles in Joomla are the main content types on a web page and can display text and images.
  • A category is a way to organize your articles.
  • A filter is used to show only content that matches the given criteria.
