User Guide: revise Languages overview intro (402)

- Edit overview-pages/402_Languages.html: rewrote the intro paragraph
  in response to colleague review feedback. Removed the "no extension
  required" claim - language packs are technically extensions - and
  told the fuller story: core language packs only translate Joomla's
  own built-in labels/prompts, while menus, articles, and other
  written content still need manual translation, and third-party
  extensions need their own language files to be fully translated.
  Dropped the "one of Joomla's strengths" framing along with it.
