Mail Templates let site administrators customise the email messages Joomla sends when users and administrators take certain actions, without touching code. Introduced in Joomla 5.2, the feature covers Joomla's own built-in templates as well as templates added by third-party extensions.

This section covers configuring Mail Templates globally, editing individual templates, sending one-off messages to groups of users, overriding the layout used by outgoing email, and looking up which placeholder tags are available in which templates.

  • Options – The global settings that apply across all Mail Templates, including mail format, attachments, template layout, and logo.
  • Editing – Opening a template in the Mail Template Editor and using its placeholder tags to customise the message it sends.
  • Mass Mail Users – Sending a one-off message to a group of users, styled and formatted using the same Mail Template system.
  • Managing Template Layouts – Overriding the default layout so you can change how every Mail Template looks, not just its text.
  • Tags Cross-Reference – A reference table showing which placeholder tags are available in each extension's Mail Templates.
