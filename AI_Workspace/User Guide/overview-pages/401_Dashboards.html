Dashboards are panel-based landing pages in the Administrator backend, giving you an at-a-glance overview and quick shortcuts before you dive into a component's own list screens. The default Home Dashboard appears when you log in, and most of the other main Administrator menus – Content, Menus, Components, Users, and System – open their own matching dashboard when you select the small dashboard icon beside the menu item. A separate Help Dashboard collects links to Joomla support resources.

  • Home Dashboard – The default landing page after logging in to the Administrator backend, made up of customisable panels of modules that surface site information and shortcuts to common tasks.
  • Content Dashboard – Opened from the dashboard icon beside the Content menu item, showing panels for the Content menu's own subsections alongside extra panels such as Popular Articles and Recently Added Articles.
  • Menu Dashboard – Opened from the dashboard icon beside the Menus menu item, with one panel for Menus & Menu Items and another listing the items in each of your site's individual menus.
  • Components Dashboard – Opened from the dashboard icon beside the Components menu item, with a panel of sub-menu links for every installed component.
  • Users Dashboard – Opened from the dashboard icon beside the Users menu item, with a panel for each Users menu group and a view of who's currently logged in; Privacy, User Actions Log, and Messaging each have their own separate dashboard.
  • System Dashboard – Opened from the dashboard icon beside the System menu item, organising core Administrator tasks into panels for Setup, Install, Templates, Maintenance, Manage, Information, Update, and User Permissions.
  • Help Dashboard – Panels of links to Joomla help and support resources, including a Joomla Help section and further links that mostly open external Joomla websites.
