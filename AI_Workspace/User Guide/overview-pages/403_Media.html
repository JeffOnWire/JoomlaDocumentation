The Media component is where Joomla stores and manages the images and files used throughout your site – the pictures in your articles, PDFs linked from a menu, and everything else uploaded through the Media manager. This section covers everyday tasks like organising, uploading, and editing files, as well as the administrator settings that control where those files are stored and what types can be uploaded.

Working with Media

The core day-to-day tasks in the Media manager: organising files into folders, uploading and removing them, and doing basic image editing without leaving Joomla.

  • Managing Media – Using the Media manager's folder structure, toolbar, and search tools to organise the images and files used throughout your site.
  • Upload Delete Rename – Adding new files to a folder, removing files you no longer need, and renaming an existing file without losing its extension.
  • Image Crop Resize Rotate – Cropping, resizing, and rotating an image directly in the Media manager, without needing an external image editor.

Media Configuration

Administrator settings that control where uploaded files are stored and which file types the Media manager will accept.

  • Media File Locations – Setting up separate storage folders for images versus other documents, and registering them with the FileSystem - Local plugin.
  • Media: Options – Configuring the Media component's storage paths, allowed file extensions, and legal MIME types.
  • Uploading SVG files – Enabling SVG uploads, which aren't allowed by default, and understanding the security sanitiser Joomla runs on them since version 4.1.
