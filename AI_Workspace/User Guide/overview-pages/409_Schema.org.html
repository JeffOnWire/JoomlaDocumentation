Schema.org is a shared vocabulary for structured data — sometimes called rich snippets — that helps search engines understand what a page is actually about, which can improve how it's displayed in search results. Joomla 5 has this built in: you can add structured data to your content through a system plugin and a set of custom fields, without a third-party extension or any coding.

This section covers turning the feature on and setting it up, then applying it to specific kinds of content: blog posts, books, events, job postings, organisations, and recipes.

Article Schema Types

Schema types available for individual articles, one for each kind of content Joomla recognises.

  • Article BlogPosting Type – Marking up a blog post with its author, publication date, and other metadata search engines use for blog listings.
  • Article Book Type – Marking up a book review or listing with details like ISBN, publication date, and format.
  • Article Event Type – Marking up an event with its name, start date, location, and organiser so it can appear in event-focused search results.
  • Article JobPosting Type – Marking up a job listing with title, location, employment type, salary, and the hiring organisation.
  • Article Organization Type – Marking up an article about a business, school, nonprofit, or similar entity with details like its name and address.
  • Article Recipe Type – Marking up a recipe with its image, cooking times, ingredients, and nutritional information.
