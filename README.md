# Jeff's Joomla Documentation Resources
Images and other resources used for Joomla documentation. 

Currently this is for new-user documentation and contains screen shots created by me, and other files.

Screenshots are created using [SnagIt](https://www.techsmith.com/snagit/) and so originals are in that format.

The project is organized into numbered folders, where the numbers correspond to article ID numbers in the [Joomla Sandbox Documentation site](https://docs-core.sandbox.joomla.org/).

## Folder Organization
Each folder contains the original screenshot files in [SnagIt](https://www.techsmith.com/snagit/) format. 

The *exports* folder contains the screenshots exported from the original files that are then uploaded to the Joomla documentation site. 

The *resources* folder contains any other external resources used (e.g. images from other sites, PDF files used in the article, etc.). 

## Process
To make screenshots I'm opening bringing up the subject page, usually the website on my local machine, in a browser, with the window width adjusted to show a laptop/desktop style layout (i.e. widest responsive design breakpoint) and sometimes wider to prevent awkward wrapping. I make a SnagIt capture of the entire window. In SnagIt I then crop the image (non-destructive crop), add borders, arrows, text, or other visual aids. The SnagIt file is saved to the article folder. I then export the image using (File > Save As). The export is saved to the *export* subfolder as a webp image with the *Scale down retina image before saving* option checked. Image sizes are coming out a little larger than what I need in the actual article, but not excessively so. I scale the image in the article.
